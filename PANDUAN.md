# Menjalankan KisahNada 0.3 di Windows

1. [Unduh KisahNada-Setup.exe](https://github.com/Rosal894/Rosal894.github.io/raw/refs/heads/kisahnada-download-0.3.0/KisahNada-Setup.exe).
2. Tutup studio KisahNada yang masih berjalan.
3. Jalankan installer, ikuti wizard, lalu pilih Buka KisahNada. WSL/Python tidak perlu dipasang manual.
4. Gunakan Cerita atau Lirik untuk menyiapkan lagu. Tema berubah melalui tombol matahari/bulan.
5. Untuk nyanyian, klik Pasang model, masuk akun studio lokal, dan konfirmasikan unduhan ACE-Step. Model besar perlu internet/disk/RAM. Mulai 30 detik setelah model terverifikasi; keberhasilan Windows belum teruji.
6. Library dan panel Lagu terbarumu menyediakan playback, suka, pencarian dan unduhan. Data/model tetap di folder pribadi instalasi sebelumnya.

Jika fitur lirik AI belum terhubung, pilih menulis sendiri atau draf template yang dilabeli bukan AI. My Voice belum didukung. Jangan mematikan antivirus/SmartScreen; jika Windows memblokir installer unsigned ini, catat pesannya untuk diperiksa.

Log dan data: tombol Folder data / log pada jendela status. Tutup studio setelah pekerjaan selesai.

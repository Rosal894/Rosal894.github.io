# Menjalankan KisahNada 0.3.1 di Windows

1. [Unduh KisahNada-Setup.exe](https://github.com/Rosal894/Rosal894.github.io/raw/refs/heads/kisahnada-download-0.3.1/KisahNada-Setup.exe).
2. Tutup studio versi lama, jalankan installer, lalu pilih Buka KisahNada.
3. Buka AI Song dan klik Pasang mesin nyanyian AI. Masuk/daftar akun studio lokal, lalu konfirmasikan unduhan model.
4. Biarkan aplikasi terbuka; model memerlukan banyak GB, internet, RAM dan ruang disk memadai.
5. Setelah model terverifikasi, tulis lirik pendek di tab Lirik, pilih Male/Female/Random dan durasi 30 detik, lalu Buat lagu bernyanyi AI.
6. Dengarkan hasil di studio/Library, kemudian unduh. Kualitas dan keberhasilan nyanyian Windows masih perlu diuji.

Worker baru memakai Python 3.12 di SongRuntime312. Data/model pada folder pribadi tetap dipertahankan. Kegagalan ditampilkan dan tidak dicoba ulang otomatis. Jika gagal, buka Folder data / log dari jendela status, lalu kirim pesan error tanpa API key/password.

Tema gelap/terang tersedia pada tombol matahari/bulan. Groq opsional memerlukan key/paket gratis sendiri; draf template bukan AI. My Voice/kloning artis belum didukung. Installer belum ditandatangani; jangan mematikan perlindungan Windows jika paket diblokir.

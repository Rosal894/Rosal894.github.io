# KisahNada Windows — versi uji 0.2

Installer Windows 10/11 x64, tanpa WSL atau pemasangan Python manual.

- [Installer KisahNada-Setup.exe](KisahNada-Setup.exe)
- [SHA256 installer](KisahNada-Setup.exe.sha256)
- [Source aplikasi yang sesuai paket](KisahNada-source.zip)
- [Panduan Windows](PANDUAN.md)

Tema terang/gelap tersedia. Nyanyian menggunakan ACE-Step melalui pemasang model di aplikasi; model besar belum dibundel. Tidak ada API key atau media pribadi. Tidak ada fallback narasi yang dianggap nyanyian. My Voice belum tersedia. Paket belum ditandatangani atau lolos pengujian langsung Windows; uji Wine terblokir oleh inisialisasi Wine. Ini bukan rilis produksi yang dinyatakan sempurna.

Runtime Python, eSpeak-NG, FFmpeg/FFprobe shared dan VC++ disertakan dengan lisensi/provenance dalam paket. Detail source dan lisensi ada di ZIP source, THIRD_PARTY_NOTICES.md dan folder licenses installer.
